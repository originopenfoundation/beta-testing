Canonical Definition

The Podcast & Streaming Module (PSM™) defines how the origin of audio
and real-time content is declared using a single, clear origin code.

The module enables immediate recognition of whether spoken or streamed content
is human generated, AI generated, or undeclared.

Declaration

Only one origin code may be used:

  • HGC — Human Generated Content
  • AGC — AI Generated Content
  • UGC — Unknown Generated Content

Usage

Content Level (required — single code)

One origin code must be associated with the podcast episode or live stream.

Examples:

  • HGC
  • AGC
  • UGC

Description Level (required)

The declaration must be included in the episode description or stream metadata: 

Origin: HGC
OOF Compatible — ODS™ Standard
https://originopenfoundation.org

Live Content Rule

For live streaming:

  • origin must be declared before or at the start of the stream
  • if origin changes during the stream, the declaration must be updated

OOF Compatibility

Content using this module may include the statement:

OOF Compatible — ODS™ Standard

A reference link to the official source is required.

Use Case 1 — Live Stream Transparency

Scenario

A creator runs live streams with human presence, AI avatars, or mixed formats.

Application

Origin is declared at the start of the stream (HGC / AGC / UGC).

Result

  • Immediate audience clarity
  • Reduced confusion about real vs synthetic presence
  • Increased trust in live content

Use Case 2 — Podcast Distribution

Scenario

A podcast is distributed across platforms with human or AI-generated voices.

Application

Each episode includes origin declaration in metadata.

Result

  • Transparent content classification
  • Improved platform compliance
  • Clear differentiation in the market

Structural Principle

Real-time content does not remove the need for declaration.

Closing Statement

Live or recorded, the rule remains the same.
Origin must be declared.
