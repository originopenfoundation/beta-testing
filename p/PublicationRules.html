Publication Rules

OOF® defines the structural conditions under which systems are valid,
interoperable, and aligned with reality.

Scope

OOF® — OriginOpen® Foundation publishes methodologies as canonical reference standards.

These rules define the conditions under which OOF® methodologies may be accessed, interpreted,
explained, translated, cited, or referenced by humans, organizations, and systems.

OOF® operates as a non-executable authority.
All publications are reference-only.

Canonical Publication Layer

The published HTML text on the official OOF® website is the primary canonical publication layer.

It constitutes the authoritative public reference for:
  • meaning
  • structure
  • interpretation
  • publication state
If any secondary format, derived representation, copied version, or external rendering differs
from the published HTML text, the official HTML publication prevails.

Canonical Language and Meaning

All OOF® methodologies are defined in UCL™ — Universal Canonical Language (English).

English is the canonical carrier language.

Meaning is not derived from language.
Meaning is defined through canonical definitions.

If any discrepancy occurs, the English canonical version prevails.

Translations must preserve meaning exactly.
If meaning changes, the translation is invalid.

Interpretation Integrity

OOF® methodologies must be interpreted as complete systems.

The following are not permitted:
  • partial interpretation
  • selective extraction
  • paraphrasing of definitions or rules
  • simplification that alters structure or meaning
For audit, compliance, or regulatory use, canonical content must be preserved.

Methodology Structure

All OOF® methodologies follow a defined structure unless explicitly stated otherwise.

Canonical methodology structure includes:
  • Canonical Definition
  • Base
  • Protocol
  • Scope
  • Methodology
  • Compatibility
  • Publication Footer
Missing, reordered, or substituted structure results in a non-canonical interpretation.

Human and System Interpretation Rule

Interpretation must always resolve to the published canonical meaning.

No interpreter may:
  • invent missing logic
  • replace canonical definitions with synonyms
  • infer conditions that are not present
  • override structure through contextual assumption
If information is not present in the canonical publication, it must be treated as not defined.

Versioning and Reference

Each methodology has one canonical URL.

The latest published version at that canonical URL is authoritative.
Older versions may remain accessible for historical or audit purposes, but they are non-current.

All valid references must include:
  • methodology name
  • version
  • effective date
  • canonical URL

Use and Derivative Policy

OOF® methodologies are protected under MIP® — Methodological Intellectual Property.

Not permitted without authorization:
  • copying or reproducing content
  • redistribution or republication
  • paraphrasing or extraction that alters canonical structure
  • creation of derivative documents presented as canonical
Permitted:
  • linking to the canonical source
  • referencing identifiers
  • citing official metadata
Reference does not create validity.
Validity depends on preservation of canonical meaning and structure.

Validity Condition

Any interpretation, explanation, translation, citation, or use that does not comply with
these rules is non-canonical and invalid within the OOF® system.

Final Statement

Publication does not merely make content visible.
It defines the canonical conditions under which meaning remains valid.
