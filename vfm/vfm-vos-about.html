About Value Origin Standard (VOS)

Architecture: VFM® — Value Flow Mechanism Category: Governance & Enforcement Subcategory: Value Lifecycle Governance Parent Standard: Value Origin Standard (VOS) Governed Space: Value Origin

Canonical Definition

Value Origin Standard (VOS) governs how the identifiable source, basis, capability, condition, activity, relationship, object, or other foundation from which value may emerge is identified, structured, related to the governed value context, and documented.

The Standard establishes the methodological starting point for understanding where value comes from before determining whether value has actually emerged.

Its central distinction is:

Value Source ≠ Existing Value

A resource, capability, asset, technology, relationship, right, activity, infrastructure, dataset, invention, natural resource, human capability, or other source may possess the potential to generate value while the corresponding value has not yet come into existence.

VOS makes that origin governable.

Why Value Origin Matters

Value is frequently measured, priced, exchanged, taxed, invested, depreciated, impaired, restored, or reported without a structured methodology for identifying its underlying origin.

This can create a fundamental analytical problem:

the observable value may be known while the mechanism from which that value originates remains poorly understood.

VOS establishes the value-origin layer before later VFM® standards govern emergence, recognition, state, change, development, degradation, nullification, restoration, or extinction.

It allows an organization to ask:

What is capable of producing this value?

What is the underlying basis of that capability?

Under which conditions can that source generate value?

What relationship exists between the source and the governed value?

Has value already emerged, or does only value potential currently exist?

Value Source Before Value Emergence

VOS separates three concepts that should not be treated as equivalent:

Source of Value

Potential for Value

Existing Value

A source may exist without producing value.

A source may possess value-generating potential without that potential being realized.

Value may emerge only when the relevant conditions, relationships, capabilities, activities, or other mechanisms become effective.

This distinction creates a clear architectural boundary between:

Value Origin Standard

and the subsequent:

Value Emergence Standard.

VOS identifies where value can come from.

Value Emergence Standard determines when value actually comes into existence.

Origin Asset™

Origin Asset™ operates as a foundational value-origin concept within this governed space.

An Origin Asset™ may represent an identifiable asset, capability, resource, condition, relationship, knowledge base, technology, infrastructure, right, process, or other foundation capable of contributing to the emergence of value.

However:

Origin Asset™ ≠ Existing Value

The existence of an Origin Asset™ does not itself prove that value has emerged.

This distinction allows dormant, unused, undeveloped, inaccessible, unactivated, or unrealized value sources to remain identifiable without artificially treating their potential value as already realized value.

What VOS Governs

VOS provides the methodological structure for identifying:

the source from which governed value may originate; the basis upon which that source possesses value-generating potential; the relationship between the source and the governed value; the conditions necessary for value to originate from that source; multiple sources contributing to one form of value; one source contributing to multiple forms of value; direct and indirect value origins; dormant or unrealized value sources; changes affecting the ability of a source to generate value; documentation of the value-origin relationship.

The Standard does not determine the price of the source or the value that may eventually emerge from it.

It establishes the origin structure from which subsequent value governance can proceed.

Why This Is Different From Asset Identification

VOS does not attempt to become an identity, ownership, accounting, property, or asset-classification standard.

An underlying object may be identified through another governance architecture.

VFM® asks a different question:

What role does this object, capability, activity, relationship, or condition play in the origin of the governed value?

Therefore:

Object Identity ≠ Value Origin

Asset Ownership ≠ Value Origin

Asset Price ≠ Value Origin

Value Source ≠ Existing Value

This separation allows VFM® to examine value across physical, digital, financial, organizational, technological, environmental, intellectual, social, and future value environments without depending upon one particular asset model.

Practical Value

Value Origin Standard can help organizations move beyond observing value only after it has already become economically visible.

By identifying value sources earlier, organizations may better understand:

where value-generating capacity exists; which capabilities remain underutilized; which dependencies support existing value; which sources contribute disproportionately to value creation; where dormant value potential exists; which source conditions must be preserved; where loss of a source could later cause value degradation; where investment may activate previously unrealized value potential.

This makes Value Origin governance relevant not only to economic analysis but also to strategic planning, infrastructure, technology, public administration, banking, investment, industry, digital assets, and emerging economic systems.

Use Case 1 — Banking and Financial

Infrastructure

A financial institution possesses extensive infrastructure including transaction networks, customer relationships, data, risk models, distribution channels, specialized expertise, technology, licenses, operational capabilities, and institutional relationships.

Traditional financial reporting may assign values to some of these elements while others remain difficult to represent as direct economic value.

VOS begins with a different question:

Which identifiable sources actually generate or enable the value being governed?

The institution can map a particular form of value back to its underlying sources and distinguish between:

an asset that exists

and

a source that is actively capable of generating value.

This can expose dormant capabilities, critical value dependencies, underutilized infrastructure, and sources whose deterioration could threaten future value.

VOS therefore creates a methodological basis for understanding where economic value originates before that value is priced, exchanged, impaired, restored, or otherwise transformed.

Use Case 2 — Space Mission and Advanced

Infrastructure

A space organization develops a reusable launch system.

The program contains enormous potential sources of value:

engineering knowledge, propulsion technology, launch infrastructure, simulation capability, manufacturing processes, reusable components, mission data, intellectual capability, operational experience, and future launch capacity.

Not every source has yet produced realized economic or operational value.

VOS allows these sources to be identified without prematurely declaring their potential value to be existing value.

For example, a new reusable propulsion capability may represent a significant Value Source because it could reduce future launch costs, increase launch frequency, extend mission capability, or enable entirely new missions.

But until the relevant conditions exist and the capability produces a governed value outcome:

Value Potential ≠ Emerged Value

This distinction allows organizations to map future value-generating capacity while preserving methodological discipline between what could create value and what value actually exists.

Relationship to the VFM® Lifecycle

Value Origin Standard occupies the second governed space of VFM®, following Value Context Standard.

The sequence begins:

Value Context → Value Origin → Value Emergence

Value Context Standard establishes:

what value is being governed.

Value Origin Standard establishes:

where that value can originate.

Value Emergence Standard subsequently establishes:

when that value actually comes into existence.

This sequence prevents value potential, value source, and existing value from being collapsed into a single concept.

Foundational Principles

Value must be identified before its origin can be meaningfully governed.

A value source may exist before value emerges.

Value-generating potential is not the same as existing value.

An Origin Asset™ may exist without having produced value.

One value may originate from multiple sources.

One source may contribute to multiple forms of value.

The source of value must remain distinguishable from the systems that price, exchange, own, classify, validate, tax, or account for it.

Canonical Closing Statement

Value Origin Standard establishes the origin layer of the governed value lifecycle by identifying the sources, bases, capabilities, conditions, activities, relationships, objects, and other foundations from which value may emerge. By separating Value Source, Value Potential, and Existing Value, the Standard enables value-generating capacity to be identified before value becomes economically, operationally, or institutionally visible. Value Origin Standard therefore provides the methodological foundation required to trace governed value back to its origin while preserving the fundamental principle that the existence of a value source does not itself establish the existence of value.
