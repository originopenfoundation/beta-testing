Canonical Definition

Value Source Identification Module (VSOIM) is the first Core Module of the Value Origin Standard (VOS).

VSOIM governs the systematic identification of the specific source, capability, condition, activity, relationship, object, resource, knowledge, right, infrastructure, process, or other identifiable basis from which the governed value may originate.

The Module establishes a fundamental starting point:

Before the origin of value can be understood, the source capable of producing, enabling, supporting, or contributing to that value must first be identifiable.

VSOIM does not determine whether value has already emerged.

It identifies where the potential origin of that value resides.

Architectural Position

VSOIM is the first module within the Value Origin Standard.

It receives the governed value context established by the preceding Value Context Standard (VCXS) and identifies the source or combination of sources potentially responsible for the origin of that value.

The internal sequence begins:

Governed Value Context → Value Source Discovery → Value Source Identification → Source Differentiation → Source-to-Value Linkage → Identified Value Source

The identified source then proceeds to:

VSBM — Value Source Basis Module

where the basis upon which that source can generate value is examined.

Operational Space

VSOIM governs the identification of value sources.

A Value Source may include:

physical assets; natural resources; infrastructure; technologies; intellectual property; knowledge; data; human capability; organizational capability; productive capacity; manufacturing capability; services; processes; relationships; networks; access; rights; permissions; locations; time advantages; operational capabilities; computational capability; energy resources; financial resources; biological resources; scientific discoveries; inventions; unused capacity;

combinations of multiple sources.

The architecture does not require value to originate from a conventional economic asset.

Anything capable of contributing to the emergence of the governed value may become a Value Source candidate.

Value Source Identification

VSOIM requires the source to be identified with sufficient specificity to distinguish it from other possible sources.

A Value Source identification should establish, where relevant:

Source Type What kind of source is involved?

Source Object What specific object, capability, activity, relationship, condition, or resource represents the source?

Source Location Where does the source exist operationally, physically, digitally, institutionally, or logically?

Source Context Within what context can the source contribute to value?

Source Function How is the source capable of contributing to the governed value?

Source Relationship What relationship exists between the source and the value under examination?

The objective is not merely to create a list of assets.

The objective is to identify the actual origin candidates of the governed value.

Value Source ≠ Asset

VSOIM establishes an important distinction:

Value Source ≠ Asset

An asset may be a Value Source.

But value may also originate from something that is not conventionally recognized as an asset.

Examples include:

collaboration between organizations; geographic position; access to infrastructure; accumulated operational knowledge; unused production capacity; network effects; timing; interoperability; reputation; human expertise; scientific insight; process improvement; reduced complexity; avoided failure; reduced resource consumption.

VFM® therefore does not limit value-origin analysis to accounting or legal asset categories.

Value Source ≠ Existing Value

Identification of a Value Source does not establish that value currently exists.

This distinction is foundational:

Value Source → may enable Value Emergence

but:

Value Source ≠ Value Emergence

A patent may exist without commercial value being realized.

A factory may contain unused productive capacity.

A dataset may exist without being operationally exploited.

A scientific discovery may exist decades before a valuable application emerges.

A natural resource may exist without economically usable extraction capability.

A computational optimization may exist before it produces measurable cost reduction.

VSOIM identifies the source.

Later VFM® governance determines what happens to value.

Single-Source Value

Some value may originate predominantly from one identifiable source.

For example:

Patent → licensing capability → economic value

or:

Energy-efficiency improvement → reduced energy consumption → operational cost value

VSOIM identifies the source without prematurely determining the amount or state of resulting value.

Multi-Source Value

Many forms of value do not originate from one source.

They emerge from combinations.

For example:

Technology + Data + Human Expertise + Infrastructure + Market Access

may together enable a valuable service that none of the sources could independently produce.

VSOIM therefore permits:

One Value ← Multiple Value Sources

The contribution of each source may later be examined without forcing the entire value origin into one artificial source.

One Source, Multiple Values

The reverse relationship is equally important.

One source may contribute to several forms of value.

For example, a satellite constellation may produce:

navigation value communication value scientific value security value commercial value infrastructure value

Therefore:

One Value Source → Multiple Governed Values

Each value remains connected to its own governed Value Context.

Direct and Indirect Value Sources

VSOIM distinguishes between direct and indirect sources where useful.

A Direct Value Source contributes directly to the emergence of the governed value.

An Indirect Value Source enables another source to generate that value.

For example:

Manufacturing Machine → direct production capability

while:

Predictive Maintenance System → increased machine availability → increased production capability.

Both may contribute to value, but through different pathways.

The distinction prevents enabling conditions from being confused with immediate value-producing sources.

Dormant Value Sources

A Value Source may exist without currently producing value.

Such a source may be:

unused; inaccessible; undeveloped; underutilized; disconnected; technologically unavailable; economically impractical; awaiting another capability; awaiting infrastructure; awaiting demand; awaiting activation conditions.

VSOIM allows these sources to remain identifiable without declaring that their potential has already become value.

This creates an important analytical category:

Identified Value Source + No Current Value Emergence

Such a condition can be strategically significant.

Hidden Value Sources

Organizations may possess sources of value that are not recognized by conventional accounting, asset-management, or operational structures.

Examples may include:

accumulated internal knowledge; unused datasets; manufacturing know-how; cross-system compatibility; spare infrastructure capacity; operational relationships; process knowledge; reusable engineering components; historical information; internal methodologies; underused intellectual property.

VSOIM provides a method for making these potential value sources visible.

It does not automatically declare them valuable.

It identifies them as candidate origins requiring further governance.

Source Dependency

A source may depend upon another source before it can contribute to value.

For example:

AI Model depends upon Data + Computing Infrastructure + Energy + Operational Access

before a particular value outcome can emerge.

VSOIM should therefore preserve materially relevant source dependencies.

This allows VFM® to distinguish between:

Independent Value Source

and

Dependent Value Source

without converting the Module into general dependency governance.

Source Combination

Some value emerges only when multiple sources interact.

A source combination may therefore itself become analytically relevant.

Example:

Battery Technology + Charging Infrastructure + Energy Availability + Vehicle Platform

may together create a value-generating capability that cannot be meaningfully attributed to one component alone.

VSOIM may therefore identify:

Composite Value Source

where the governed value originates from a defined combination of sources.

Source-to-Value Linkage

Every identified Value Source should be linked to the governed value established under the Value Context Standard.

The linkage should answer:

Why is this source relevant to this specific governed value?

A source should not be included merely because it exists.

There must be a plausible value-origin relationship.

This relationship is then examined more deeply by the subsequent Value Origin modules.

Source Identification State

For practical implementation, VSOIM may classify source identification as:

1. Candidate Source

A possible source has been identified but the relationship to governed value remains insufficiently established.

2. Identified Source

The source and its plausible relationship to the governed value are sufficiently distinguishable.

3. Composite Source

The governed value depends upon an identifiable combination of sources.

4. Dependent Source

The source requires another source or enabling condition before it can contribute to value.

5. Unresolved Source

The governed value is observable or suspected, but its source cannot yet be sufficiently identified.

These states allow organizations to work with uncertainty without inventing a source that evidence does not support.

Minimum Implementation Framework

A practical VSOIM implementation should establish:

1. Governed Value Context

Identify the value context received from the Value Context Standard.

2. Candidate Source Discovery

Identify potential sources capable of contributing to that value.

3. Source Identification

Define the specific source sufficiently to distinguish it from alternatives.

4. Source Type

Determine whether the source is an object, capability, resource, activity, relationship, condition, right, knowledge base, infrastructure, process, or another source type.

5. Source Relationship

Establish the plausible relationship between the source and governed value.

6. Source Structure

Determine whether the source is single, composite, direct, indirect, independent, or dependent.

7. Source State

Determine whether the source is active, dormant, underutilized, inaccessible, undeveloped, or otherwise materially constrained.

8. Source Identification Record

Preserve the identified source and its relationship to the governed value for downstream Value Origin governance.

Governance Outputs

VSOIM may produce:

Value Source Candidate Record Value Source Identification Record Value Source Type Value Source-to-Value Link Direct Value Source Record Indirect Value Source Record Composite Value Source Record Dependent Value Source Record Dormant Value Source Record Unresolved Value Source Record Value Source Map

These outputs provide the input basis for VSBM — Value Source Basis Module.

Use Case 1 — Banking: Identifying Underused

Sources of Value

A bank may traditionally evaluate value through revenue, assets, deposits, loans, investments, and other recognized financial measures.

VSOIM can expand the analysis to identify the underlying sources from which future value may originate.

These could include:

transaction data + customer relationships + payment infrastructure + risk expertise + distribution network + regulatory capability + technological infrastructure.

The Module does not assign monetary value to those sources.

Instead, it identifies which capabilities may actually be responsible for producing particular forms of value.

This allows the institution to distinguish between:

what it owns

and

what actually possesses value-generating capability.

Use Case 2 — Space Mission: Finding Value in

Cost Reduction

A space organization develops a reusable launch architecture.

The obvious Value Source may appear to be the launch vehicle itself.

VSOIM may reveal that the governed value—such as lower cost per mission—actually originates from several interacting sources:

reusable propulsion + rapid inspection capability + reusable structures + automated diagnostics + launch infrastructure + operational knowledge.

The launch vehicle alone does not explain the value origin.

The value may originate from the combined capability to reuse the system repeatedly at lower marginal cost.

VSOIM identifies that source structure before VFM® determines whether the expected cost-reduction value has actually emerged.

Foundational Principles

Value cannot be traced to its origin until its source is identifiable.

A Value Source is not automatically an asset.

An asset is not automatically a Value Source.

A Value Source is not Existing Value.

Potential value is not Emerged Value.

One value may originate from multiple sources.

One source may contribute to multiple forms of value.

A dormant source may remain strategically important even while producing no current value.

Source identification must remain connected to the governed Value Context.

Canonical Closing Statement

Value Source Identification Module establishes the first operational layer of Value Origin governance by identifying the specific sources, capabilities, resources, activities, relationships, conditions, objects, knowledge,

rights, infrastructure, processes, and source combinations from which governed value may originate. By distinguishing Value Sources from assets, Existing Value, Value Emergence, and external identity or ownership structures, VSOIM enables organizations to identify direct, indirect, composite, dependent, dormant, underutilized, and unresolved sources of value without prematurely asserting that value already exists. The Module therefore creates the traceable starting point required to determine not merely that value may exist, but where its potential origin can actually be found.
